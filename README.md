# Sitio Colaborativo

Sitio web de práctica con una página de inicio y una página de contacto, construido con HTML y CSS. Sirve para practicar un flujo de trabajo profesional con Git y GitHub: issues, ramas, pull requests y versiones.

## Instalación

1. Clona el repositorio:

   ```bash
   git clone https://github.com/Rijhoseph/sitio-colaborativo.git
   ```

2. Entra en la carpeta del proyecto:

   ```bash
   cd sitio-colaborativo
   ```

No requiere instalar dependencias.

## Uso

Abre el archivo `index.html` en tu navegador. Desde el menú de navegación puedes ir a la página de contacto (`contacto.html`).
